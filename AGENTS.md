# leasetracker-demo: notes for coding agents

**Public** repo. It distributes the LeaseTracker Android demo as GitHub releases (`Leasetracker-demo.apk`). The app's source is in a private repo. Never commit secrets, `.env` files, keys, private documents, or details about the account's private repos here.

Rules: `main` is the source of truth. Work on a branch, open a pull request, and delete the branch after it is merged or closed. The account-wide repo map (`REPOS.md`) lives only in the private repos.
