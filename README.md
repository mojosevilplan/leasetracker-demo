# Leasetracker demo

Demo build of the Leasetracker Android app for trying out the functionality.

**Download:** see the latest [release](../../releases/latest) and open `Leasetracker-demo.apk` on an Android phone (Android 8.0+).

## Install

1. Open the APK on the phone and tap **Install**.
2. If Android blocks it, allow "Install unknown apps" for the app you opened the file from (Chrome, Drive, etc.).
3. Open **Leasetracker**. It starts with example numbers; use the **Contract** tab to enter your own.

This is a debug build for evaluation, not a Play Store release. Data stays on the phone.
